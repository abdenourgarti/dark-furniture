# Photos du savoir-faire

Déposez ici trois photos nommées `01.jpg`, `02.jpg` et `03.jpg`, au format
paysage 4:3, environ 1400 px de large.

| Fichier | Sujet attendu |
|---|---|
| `01.jpg` | Le relevé : un membre de l'équipe en train de mesurer, mètre ou télémètre en main |
| `02.jpg` | La découpe : panneau sur la scie, ou plaquage de chant en atelier |
| `03.jpg` | L'assemblage : montage d'un caisson, réglage d'une charnière, gros plan sur les mains |

Tant qu'un fichier manque, la vignette affiche une plaque « Photo à venir » au
lieu d'une image cassée.

Ces trois photos sont celles qui font la différence sur ce type de site : elles
prouvent que la fabrication est réelle. Privilégiez la lumière naturelle de
l'atelier et cadrez sur les mains et l'outil plutôt que sur la machine entière.

Les libellés sous chaque photo se modifient dans les dictionnaires, clé `craft.items`.
