# Photos des services

Dossier **facultatif**. Chaque carte de la section « Nos services » affiche la
photo si le fichier existe, et son icône dessinée sinon. Les deux occupent
exactement la même place : ajouter une photo plus tard ne décale rien sur la
page.

Extensions acceptées, par ordre de priorité :
`.webp` · `.avif` · `.jpg` · `.jpeg` · `.png`

Le nom du fichier doit être exactement celui de la première colonne.

| Fichier | Carte |
|---|---|
| `kitchen` | Cuisines équipées |
| `dressing` | Dressings |
| `bedroom` | Chambres adultes |
| `kids` | Chambres enfants |
| `tv` | Meubles TV |
| `office` | Bureaux |

Exemple : `public/images/services/kitchen.jpg`.

## Cadrage

Paysage 16:10, environ 1200 px de large. Une pièce terminée, photographiée de
face ou en léger trois-quarts. La carte recadre automatiquement, mais une image
déjà au bon format perd moins de sujet.
